# Support

- 📖 **Using the app** — start with the
  [user guide](docs/user/README.md); the
  [troubleshooting page](docs/user/troubleshooting.md) covers the common
  problems.
- 🐛 **Bugs** — [open an issue](https://github.com/health-assistant-io/health-assistant-android/issues/new?template=bug_report.md)
  with your app version, Android version, and what you expected vs. what
  happened.
- 💡 **Feature ideas** — [open a feature request](https://github.com/health-assistant-io/health-assistant-android/issues/new?template=feature_request.md).
- 🔒 **Security** — see [SECURITY.md](SECURITY.md); never open a public
  issue for security problems.
- 🏥 **Server-side questions** — this is the companion app; the Health
  Assistant server + bridge live in
  [health-assistant](https://github.com/health-assistant-io/health-assistant).

Self-hosted software, community-supported — please be patient and kind.
