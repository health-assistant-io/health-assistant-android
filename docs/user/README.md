# User guide — Health Assistant app

How to use the Android companion app for your self-hosted Health Assistant
instance: connect it, read your health data natively, and keep it working
offline.

## The 30-second version

1. Install the app, scan the **connect QR** from your instance's bridge
   screen (or tap *Open in app* on that page).
2. Choose how you want to use the app: **Simple** (just the essentials) or
   **Advanced** (everything). You can switch anytime in Profile.
3. Grant **Health Connect** permissions for the types you want to sync.
4. Your data flows: on-device readings push to your instance; biomarkers,
   examinations, medications, documents, and notifications read back natively
   — and stay readable offline.
